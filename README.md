# 🐱 桌面宠物 Desktop Pet

> 物光创新实验室 2026 年招新作品 · 作者：zhongwang

一个用 **Python + tkinter** 实现的桌面宠物程序。**无需任何外部图片素材**——角色全部由 Canvas 矢量图形实时绘制，自包含、零资源依赖，下载即跑。

---

## ✨ 功能一览

| # | 功能 | 说明 |
|---|------|------|
| 1 | **点击互动** | 点身体弹随机表情气泡，点头部 = 摸头（舒服~） |
| 2 | **长按拖拽** | 按住拖拽宠物，松开时根据**拖拽方向**触发不同物理动作 |
| 3 | **声音跳舞** | 检测到环境声音/音乐时自动跳起来跳舞（可选依赖） |
| 4 | **天气系统** | 自动定位并获取当地天气：按温度换装、雨天打伞、大风被吹、四季场景 |
| 5 | **日历节日** | 春节/中秋/国庆等节日切换主题，春节点击可放烟花鞭炮 |
| 6 | **待机 AI** | 闲置后随机进入学习、看书、睡觉；点击睡觉的宠物会惊醒 |

### 拖拽方向力学（对应设计草图）

```
        ① 竖直向上 ──→ 起跳腾空
       ╱ ② 斜向上  ──→ 斜向飞跃
      ╱
宠物 ────── ④ 斜向下 ──→ 平移滑行
      ╲
       ╲ ③ 竖直向下 ──→ 自由落体 → 着陆站起
```

- ① 向上拖：宠物获得向上初速度，重力下落，啪地着陆
- ② 斜向上拖：抛物线飞跃，稳稳落地
- ③ 向下拖：自由落体，咚一声站起来
- ④ 斜向下拖：地面滑行，逐渐减速

## 🚀 快速开始

### 环境要求
- Python 3.8+
- Windows / macOS / Linux 桌面环境（Windows 下透明背景效果最佳）

### 运行

```bash
# 基础运行（仅用标准库，无需安装任何依赖）
python pet.py
```

### 启用声音跳舞（可选）

```bash
pip install sounddevice numpy
python pet.py
```

> 未安装这两个包时，跳舞功能自动降级关闭，其余功能正常。也可通过**右键菜单 → 让它跳舞**手动触发。

## 🏗️ 架构设计

```
pet.py
 ├── WeatherService     天气服务（IP定位 + open-meteo，免费无key）
 ├── FestivalService    节日日历（2026主要节日）
 ├── SoundMonitor       声音监听（可选，麦克风RMS阈值检测）
 └── DesktopPet         桌宠主体
      ├── 状态机         idle/happy/pat/drag/jump/leap/fall/slide/
      │                  dance/study/read/sleep/wake
      ├── 物理引擎        重力 + 初速度 + 着陆检测
      ├── Canvas 绘制     角色矢量图形 + 表情 + 道具 + 场景
      └── 事件循环        30fps after() 定时刷新
```

### 核心设计思路

1. **零素材**：角色用 `create_oval/arc/line/polygon` 实时绘制，表情通过切换眼睛/嘴巴画法实现，避免二进制资源依赖
2. **状态机驱动**：所有行为由状态机统一管理，状态间自动流转（如跳跃→落地→idle）
3. **物理模拟**：拖拽释放后按方向赋初速度，每帧施加重力，触地后归零——实现真实的跳跃/下落手感
4. **天气联动换装**：根据温度区间（≥28热/≥18暖/≥8凉/<8冷）切换身体配色，雨天自动打伞
5. **优雅降级**：声音检测为可选依赖，网络请求失败时用默认坐标/默认天气兜底

## 📝 开发中遇到的问题与解决

| 问题 | 解决方案 |
|------|----------|
| tkinter 窗口透明背景跨平台不一致 | Windows 用 `-transparentcolor`，非 Windows 降级为浅色背景 |
| 无外部图片如何表现角色 | 全部用 Canvas 矢量图形绘制，表情靠眼睛/嘴巴画法切换 |
| 拖拽方向如何准确判断 | 用 `atan2(-dy, dx)` 计算角度，划分四个扇区对应四种动作 |
| 声音检测依赖可能缺失 | try/except 导入，缺失时 `SOUND_AVAILABLE=False` 自动降级 |
| 天气 API 需要 key | 用 open-meteo（免费无key）+ ip-api 定位，均无需注册 |
